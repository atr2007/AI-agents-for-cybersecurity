# AI Agents for Cybersecurity — Learning Fork

This repository is a **personal learning fork** of the original
[AI-agents-for-cybersecurity](https://github.com/santosomar/AI-agents-for-cybersecurity) project by Omar Santos.

The purpose of this fork is **hands-on experimentation and analysis** while building practical skills in AI security concepts such as embeddings, clustering, RAG, and agent-based workflows.

---

## What I’ve Done So Far

- **Part 1 – Foundations**
  - Ran the CVE embeddings and clustering pipeline
  - Analyzed PCA and t-SNE visualizations for semantic grouping
  - Reviewed cluster size imbalance, CWE distributions, and severity skew
  - Interpreted implications for vulnerability triage and early risk prioritization

Notes and outputs reflect **execution, interpretation, and learning**, not original authorship of the underlying framework.

---

## Goals for This Fork

- Build intuition for how LLM embeddings encode security-relevant meaning
- Evaluate where unsupervised methods are useful (and where they break)
- Extend experiments incrementally while keeping scope realistic
- Develop judgment around applying AI techniques to real security workflows
